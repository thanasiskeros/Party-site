🕷️ Transistor Party - Landing Page
A modern, interactive landing page built for a student event/party. Designed with a dark and edgy aesthetic, featuring custom animations and a fully responsive layout to provide an engaging user experience.

🔗 Live Demo: https://transistorpart2.netlify.app/

 Features
Dark/Light Mode Toggle: Users can switch between themes dynamically, with custom styling for every element in both modes.

Interactive Animations: Includes a custom preloader, a typing effect for the hero text, and a unique spider animation triggered by scroll events.

Responsive Design: Fully optimized for mobile devices, ensuring the menu, grid layouts, and typography scale perfectly on all screen sizes.

Merch Section: A product showcase grid featuring 3D flip animations on image hover/click.

Custom Modals: Features an automatic pop-up overlay (timed delay) to encourage Instagram follows.

🛠️ Built With
HTML5: Semantic markup and structured content.

CSS3: Flexbox, CSS Grid, Media Queries for responsiveness, and Keyframe Animations.

Vanilla JavaScript: Used for DOM manipulation, theme toggling, scroll detection, and controlling the custom typing/timing events. No external JS libraries were used.
